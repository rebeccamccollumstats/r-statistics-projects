# R Statistics Projects

This repository is a portfolio of R-based statistics and data analysis projects. It demonstrates my ability to clean data, explore patterns, create visualizations, apply statistical methods, build models, and communicate results clearly.

## About This Repository

The goal of this repository is to show practical statistics and data science skills using R. Projects may include exploratory data analysis, probability, hypothesis testing, regression, statistical modeling, forecasting, and data visualization.

I primarily use R for statistical analysis, modeling, and visualization, with additional experience in Python and SQL for broader data science workflows.
