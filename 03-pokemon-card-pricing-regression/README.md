# Pokémon Card Price Prediction

## Project Overview

This project analyzes an e-commerce Pokémon card pricing dataset to examine which card and listing features are associated with market price. The goal is to clean the data, explore pricing patterns, build regression models, and evaluate model performance.

## Research Question

What factors most strongly influence the listed price of Pokémon cards in an e-commerce marketplace?

## Methods

- Data cleaning
- Exploratory data analysis
- Data visualization
- Log transformation of price
- Linear regression modeling
- Model diagnostics
- Train/test evaluation
- RMSE and MAE evaluation
- Business interpretation
