## Projects

This repository contains five R-based statistics and data science projects that align with my LinkedIn portfolio. 
Each project is designed to demonstrate applied statistical reasoning, data cleaning, visualization, modeling, and clear interpretation of results.

| Project | Description | Skills Demonstrated | Status |
|---|---|---|---|
| Project 1 | Anime Ratings, Genres, and Popularity: an exploratory data analysis project using R to examine rating patterns, genre trends, popularity measures, and audience engagement in anime data. | R, tidyverse, ggplot2, data cleaning, exploratory data analysis, descriptive statistics, visualization, genre analysis, insight communication | Planned |
| Project 2 | Magic: The Gathering Card Ratings Analysis: a hypothesis testing project using R to compare card ratings across rarity, color, mana value, and card-type groups from the Outlaws of Thunder Junction set. | R, tidyverse, ggplot2, hypothesis testing, confidence intervals, t-tests, ANOVA, chi-square tests, group comparison, visualization, interpretation | Planned |
| Project 3 | Pokémon Card Price Prediction: an e-commerce pricing analysis using R to examine which card and listing features are associated with market price and to evaluate regression model performance. | R, tidyverse, ggplot2, linear regression, log transformation, model diagnostics, RMSE/MAE, visualization, business interpretation | In Progress |
| Project 4 | Coffee Sales Forecasting: a time series analysis project using R to examine vending machine coffee sales trends, seasonality, purchasing patterns, and short-term sales forecasts. | R, tidyverse, ggplot2, lubridate, time series analysis, forecasting, trend analysis, seasonality, model evaluation, visualization, interpretation | Planned |
| Project 5 | Coffee Quality Analysis: an advanced analytics project using R to examine sensory attributes, processing methods, origin factors, and quality scores from Coffee Quality Institute data. | R, tidyverse, ggplot2, PCA, clustering, correlation analysis, feature engineering, multivariate analysis, predictive modeling, interpretation | Planned |
